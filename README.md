# Core ML Architecture & Implementations

## 📌 Overview
This repository is dedicated to deeply understanding the mathematical foundations of machine learning and deep learning algorithms by translating them into object-oriented code. 

By comparing **pure matrix operation-based implementations (From Scratch)** with **industry-standard framework implementations**, this project demonstrates both mathematical intuition and software engineering proficiency.

## 📂 Project Structure
Each algorithm directory shares a consistent structure (`from_scratch.py` and `framework.py`) to facilitate direct comparison of execution speed, accuracy, and logic.

- `01.linear_regression/` : Univariate/Multivariate Linear Regression and Gradient Descent
- `02.logistic_regression/` : Binary Classification and Cross-Entropy Loss
- `03.decision_tree_and_ensemble/` : Information Gain-based Splitting and Ensembles
- `04.neural_network/` : Multi-Layer Perceptron (MLP) and Backpropagation
- `05.k_means_clustering/` : Centroid Initialization and Optimization
- `06.anomaly_detection/` : Gaussian Distribution-based Anomaly Detection
- `07.recommender_system/` : Collaborative Filtering
- `08.reinforcement_learning/` : State-Action Value Optimization
